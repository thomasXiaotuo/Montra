# Montra cloud edition

## 日常使用

电脑和手机打开同一个云端网址，输入你设置的账本密码即可。
填金额、日期、类别和可选备注，点击“保存账单”。日期默认今天。
其他设备在页面打开时每 10 秒更新一次，也可以手动刷新。
每页 10 条；点击每笔记录的“编辑”修改。SQL 工作台在“高级工具”中，默认折叠。
“导出备份”可下载所有账本及其账单。手机浏览器可把网址添加到主屏幕。

## 首次设置

1. 注册自己的 [Cloudflare 免费账号](https://dash.cloudflare.com/sign-up)。
2. Mac 双击 `publish-cloud.command`，Windows 双击 `publish-cloud.cmd`，Linux 运行 `publish-cloud.sh`。
3. 浏览器中设置账本密码（至少 4 个字符），点击“连接 Cloudflare 并启用账本”。
4. 在 Cloudflare 官方页面登录并允许连接，返回设置页等待网址出现。
5. 点击“复制网址，发到手机”。以后无需打开设置窗口，家里的电脑也可关机。

这一步需要 Node.js 22+。设置入口会自动安装发布工具；日常记账不需要安装任何软件。
保留设置窗口直到发布完成。不要向任何聊天发送 Cloudflare 密码或验证码。

## 数据和访问

- 这是一个人、一个网址、多本私有账本的版本；你的设备共享同一个登录密码。
  不是让互不认识的用户注册并各自建账本的公共服务。
- 公开网址中的账单 API 始终要求登录。四个字符是允许的最短长度，初次设置由你选择。
  本机版本仍可关闭密码；云端版本保留登录保护。
- 首次迁移前，程序把本机账单保存到 `.montra/cloud-migration/ledger.json`，上传后逐项核对。
  原 SQL Server 数据不变。首次迁移后以云端账本为准，本机旧账本不会继续双向同步。
- 重新发布只更新程序，不再次导入旧账单，不重设现有云端密码。
- 登录数据和账单分别保存在两个 D1 数据库。工作台仅连接账单数据库。
- 云端 SQL 使用 SQLite：表名为 `jilu`，`SELECT ... LIMIT 50` 替代 SQL Server 的 `TOP`。
  支持查询，以及向 `jilu` 新增、修改；SQL 自动限定在当前选中的账本，`jilu` 表名不变。不允许 DELETE、DDL、PRAGMA、ATTACH 或显式事务。
  多条语句按顺序独立提交，运行错误不会撤回前面已经成功的语句。仍支持单独一行 GO 分隔。

## 免费方案

只使用 Workers Free、D1 免费额度和平台提供的 `workers.dev` 网址。
不购买域名、服务器或升级套餐。D1 读写达到每日限额会暂时不可用，存储达到限额则不能继续新增。
平台政策和额度可能变化；免费额度不等于永久无条件可用。

- [Workers 免费额度](https://developers.cloudflare.com/workers/platform/pricing/)
- [D1 免费额度](https://developers.cloudflare.com/d1/platform/pricing/)
- [平台免费网址](https://developers.cloudflare.com/workers/configuration/routing/workers-dev/)

初次发布需要你的 Cloudflare 授权，才能核验账号、免费网址和真实云端访问。
发布工具不会开通付费套餐。若账号有多个 Cloudflare 账户，会停止并要求先明确使用哪个账户。
发布失败可重新双击入口；已创建的资源会复用，已存在的不同账单不会被覆盖。

## 添加和切换账本

页面顶部选择“账本”，点击“＋ 添加账本”，输入如“生活”“旅行”“工作”的名称即可。
新账本从空白开始；旧记录保留在“默认账本”。同名账本会提示更换名称，重复提交不会重复创建。
各账本的记录、类别、支出分布、月统计和累计余额独立。每本账仍然每页 10 条。
切换账本会重置筛选和页码，并在当前页面保留各账本未保存的新增草稿和 SQL 草稿。
每个标签页、每台设备可以独立选择当前账本；账本列表和已保存记录会自动刷新。
SQL 的查询、新增、修改均只作用于当前账本，不需要自行填写账本编号。
“设置 → 导出备份”导出 `montra-books-v1`，包含所有账本名称和记录。

升级前，发布程序会将当时的云端记录另存为受保护的 `.montra/cloud-before-books-*.json`，
再把原记录归入默认账本，逐条核对后才发布。以后更新不会重新导入本机旧记录。

## 三个系统的登录和退出

已连接云端的 macOS、Windows、Linux 包都附带公开网址和 `open-ledger.html`。解压后打开这个文件，或双击系统入口，即可使用同一份云端账本，不需要安装本机数据库或 Node.js。Linux 脚本需要 xdg-open；也可以在任意系统直接用浏览器打开 HTML 文件。复制安装包不会复制登录状态。

日常输入账本密码，点击“登录”；右上角“设置 → 退出登录”只退出当前浏览器。同一浏览器其他标签页也会退出，其他电脑和手机保持登录。退出会清除本页的账单、SQL 结果和未保存草稿；不会删除云端记录。即使暂时断网，也会先清除本地显示，联网后需要重新登录。

当前是一个私有登录管理多本账本，不提供公开注册或多个独立用户账号。这里的登录密码与 Cloudflare 管理账号不同。包中不包含账单、密码、会话或 Cloudflare 凭据。
