已知设计差别（不是这次发现的功能丢失）
1. 云端密码不能关闭；本机模式仍可关闭。当前是一个私有登录管理多本账本，没有公众注册或多个独立用户账号。
2. 云端 SQL 使用 SQLite，本机使用 SQL Server。云端用 LIMIT 替代 TOP；不支持 SQL Server 的全部语法、临时表、显式事务或管理命令。查询、INSERT、UPDATE 均保留。
3. 本机 SQL Server 与云端不持续双向同步。现在日常启动默认进入云端；本机模式的程序文件和工具仍保留。
