# 使用边界

Montra面向单人本机使用，服务绑定 127.0.0.1。没有多用户登录、权限管理或面向公网的身份验证，不应直接公开服务端口。

SQL 工作台以配置的 SQL Server 账号执行代码，默认连接 jizhang，但用户可以执行该账号有权限执行的 T-SQL。它是数据库管理入口，INSERT、UPDATE、DELETE、DDL 都会作用于真实数据库。不得接受不可信用户提交的 SQL。

表单录入及筛选使用参数化查询。SQL 工作台支持用户主动输入 SQL，与参数化表单属于不同功能。每次执行最多 12 KB、20 个 GO 批次、约 30 秒，最多保留 1,000 行查询结果。错误或超时不会自动撤销已提交的前面语句；执行完成时未提交的事务会回滚。

已有 Docker 容器的密码只在服务端读取，手动输入的密码只保存在进程内存。密码不会返回给前端，不保存在源码。`.env`、备份及个人数据必须保持在仓库之外。

报告漏洞时请只提供最小可复现步骤，勿附真实密码或账单。仓库公开后建议启用 GitHub Private Vulnerability Reporting。
