记账软件（Montra）Windows 使用说明

双击桌面“打开记账软件”快捷方式，或本文件夹中的“打开记账.cmd”。
启动后在浏览器访问 http://127.0.0.1:3210（可在 .env 配置 PORT）。
服务在后台运行，关闭浏览器不会停止服务；重复启动会打开已有界面。
启动失败时查看本文件夹内的“运行日志”。

本次检查结果：
1. 本机已安装 Node.js v24.13.1，可以启动网页界面。
2. 压缩包是程序源码及依赖，不包含账单数据库、SQL Server 数据文件或数据库备份，也没有含密码的 .env。
3. 检查时未发现 Docker 命令、常见安装位置的 Docker Desktop 或本机 SQL Server 服务，默认数据库端口没有监听。
4. 因此界面可以打开，但当前还不能读取、添加或修改真实账单。

要使用原有账单：需要从原电脑备份并迁移 SQL Server 的 jizhang 数据库，或连接到仍然保存该数据库的服务器，并配置连接信息。只有这个 ZIP 无法恢复原有账单。
不要为了迁移账单而直接建立空数据库；空库不包含原来的记录。

文件整理：
程序文件直接放在“记账软件”内，没有额外的“记账数据库”外层目录。
全部普通文件均保留，原有 dist、测试结果和 Git 历史保留原状。
只略过 Mac 的 __MACOSX、.DS_Store 和六个不能直接用于 Windows 的命令符号链接；这些原始内容仍完整保存在“原始压缩包备份\记账数据库.zip”。
Mac 的 .command 启动文件保留，但在 Windows 请使用新建入口。
此整理过程没有执行数据库初始化、导入、删除或更新。
