Montra macOS 运行测试报告
测试日期：2026-10-16

结论
本机测试通过，可以启动并正常连接现有账本。本轮覆盖的主要使用流程未发现其他阻塞问题。

测试环境
- Apple Silicon / arm64
- macOS 27.0.1
- Node.js 24.20.0、npm 11.19.0
- Docker Desktop、现有 sqlserver 容器
- Google Chrome、Playwright WebKit 27.2（Safari 同类引擎，非 Safari 应用本身）
- 工作目录：/Users/xiaotuo/Desktop/meC/Montra

已修复
1. start.command 和 launch.command 缺少可执行权限，影响双击启动。现已恢复两者的执行权限。
2. 原启动测试直接比较 /var 与 /private/var 路径，导致 macOS 下误报失败。现改为解析真实路径。

新增验证
- Mac 两个启动入口的执行权限、中文及含空格的目录、跨目录启动、错误退出状态。
- WebKit 浏览器测试支持。
- 独立随机测试库的真实浏览器/HTTP/SQL 集成测试 test/live-browser-check.mjs。
- README.md 中补充 WebKit 和真实数据库测试方式。
